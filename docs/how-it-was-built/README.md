# 만든 과정

[English](README.en.md)

"나만의 AI 동화책"은 Claude Code가 만들었어요. 사람이 준 것은 지시서 한 장, 화면 시안 5장, 보조 작업자 정의 3개예요. Claude Code는 지시서를 처음부터 끝까지 읽고 구현, 검사, 문서, 배포까지 했어요.

## 이 폴더에 있는 것

| 파일 | 무엇인가 |
|---|---|
| [`STORYBOOK_BUILD.md`](STORYBOOK_BUILD.md) | 지시서. 무엇을 만들지, 지킬 제약, 쉬운 말 기준, 작업 순서, 스스로 검증하는 방법, 완료 조건이 들어 있어요. |
| [`design/`](design/) | 화면 시안 5장(시작, AI 연결하기, 이야기 씨앗, 그림, 꾸미기). 디자인 도구 형식(`.dc.html`)이라 브라우저에서 그대로 열리지 않아요. 배치, 문구, 색, 크기를 읽는 용도예요. |
| [`agents/`](agents/) | 보조 작업자 정의 3개. `builder`(구현과 검사 코드), `writer`(한국어·영어 문서), `checker`(검사 실행과 요약). |

지시서에는 보조 작업자 정의가 `agents-setup/` 폴더에 있다고 적혀 있어요. 공개하면서 이 폴더의 `agents/`로 옮겼어요. 쓰려면 `.claude/agents/`에 복사해요.

## 누가 무엇을 했나

**사람이 한 일**

- 무엇을 만들지 정하고 요구를 정리했어요.
- 지시서와 화면 시안을 쓰고, Claude Code가 낸 결과를 검토했어요.
- 자동 도구로 열리지 않는 AI 회사 약관을 브라우저로 직접 읽고 확인했어요.

**Claude Code가 한 일**

- 구현: 화면, 저장, AI 연결부, 책 내보내기
- 검사: 단위 검사, 끝까지 가보기 검사, 키 새는지 검사, 번역 빠짐 검사
- 문서: 한국어·영어 설명문, 선생님 안내서, 키 안내, 권리 안내, AI 회사 공식 문서 확인 기록
- 배포: GitHub 저장소와 GitHub Pages

## 지시서와 지금 코드가 다른 곳

지시서는 처음 만들 때의 것이라 지금 코드와 다른 곳이 있어요. 지시서는 고치지 않고 그대로 두었어요. 예를 들면 아래와 같아요.

- 지시서는 Google Gemini 키만 다뤄요. Claude와 OpenAI 키 지원은 나중에 더했어요.
- 지시서에 적힌 파일 경로(`design/`, `agents-setup/`)는 처음 폴더 기준이에요.

지금 동작은 저장소의 코드와 [`docs/DECISIONS.ko.md`](../DECISIONS.ko.md), [`docs/PROVIDER_NOTES.md`](../PROVIDER_NOTES.md)를 보세요.
