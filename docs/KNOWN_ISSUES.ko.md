# 알려진 한계

줄인 기능은 없다. 아래는 확인하지 못했거나 알고 있는 한계다.

## 확인하지 못한 것

- **실제 Gemini 호출을 해 보지 못했다.** 만들 때 `GEMINI_API_KEY`가 없었다. 실제 연결부는 공식 문서(2026-11-14)의 요청·응답 모양대로 만들었고, 가짜 네트워크로만 검사했다. 실제 키로 확인이 필요한 것:
  - 브라우저에서 `generativelanguage.googleapis.com`을 직접 부를 수 있는지 (CORS). 문서에서 답을 찾지 못했다.
  - 그림 AI가 `safety_settings`를 받는지. 받지 않으면 그 값을 빼고 한 번 다시 보내게 해 두었다.
  - 그림 요청의 `Api-Revision` 머리글이 꼭 있어야 하는지.
  - 그림이 막혔을 때 응답이 문서의 오류 코드대로 오는지.
- 키가 있으면 `GEMINI_API_KEY=... npx playwright test e2e/real-api.spec.ts`로 실제 호출 검사 1개를 돌릴 수 있다.
- 무료 한도의 분당·하루 횟수는 공식 문서에 숫자가 없어서 적지 못했다. Google AI Studio에서 확인해야 한다.
- 자동 검사는 Chromium에서만 돌렸다. Safari와 Firefox는 직접 써 보지 않았다. Safari에서는 쪽을 그림으로 바꿀 때 처음 한 번 그림이 빠지는 일이 있다고 알려져 있다. 그럴 때는 받기 단추를 한 번 더 누른다.

## 알고 있는 한계

- **나이 조건.** Gemini 약관은 18세 미만이 쓰는 서비스에 연결하는 것을 막는다. AI 연결을 학생 기기에서 켤지는 운영하는 사람이 정해야 한다. `PROVIDER_NOTES.md` 2장을 본다.
- 키를 브라우저에 둔다. 서버가 없는 구조라서 어쩔 수 없다. 같은 기기를 쓰는 다른 사람이 키를 볼 수 있으므로 "이 기기에서 키 지우기"를 꼭 안내한다. Google 문서는 키를 브라우저 쪽에 두지 말라고 권한다.
- 이 기기에 저장되는 책은 한 권이다. 여러 권은 작업 파일로 나눠 둔다.
- 브라우저 저장 공간을 지우면 만들던 책도 지워진다. 작업 파일을 받아 두는 것이 안전하다.
- 주인공 모습은 주인공 카드(글)로만 맞춘다. 기본 그림 AI는 참고 그림을 받는지 확인하지 못했다. "자세한 설정"에서 다른 그림 AI를 고르면 첫 그림을 참고 그림으로 보낸다.
- 손글씨 글꼴(Gaegu)은 자주 쓰는 한글 2,350자만 담고 있다. 없는 글자는 또박또박 글씨로 보인다.
- 글이 글상자보다 길면 넘친 부분은 보이지 않는다. 글상자를 키우거나 글자 크기를 줄인다.
- 글상자는 쪽마다 하나다.
- 인쇄용 PDF의 색은 화면 색(RGB)이다. 인쇄소에서 CMYK로 바꾸면 색이 조금 달라질 수 있다.
- 연습 모드의 수채화 예시 그림은 가장자리가 조금 거칠게 보인다. 번짐 효과 때문이다.
- 처음 열 때 글꼴 세 개(합쳐서 약 1.7MB)를 받는다. 느린 인터넷에서는 글자가 먼저 기본 글꼴로 보였다가 바뀐다.
