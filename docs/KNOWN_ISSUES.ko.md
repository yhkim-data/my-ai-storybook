# 알려진 한계

줄인 기능은 없다. 아래는 확인하지 못했거나 알고 있는 한계다.

## 확인하지 못한 것

- **세 회사 모두 실제 키로 글이나 그림을 받아 보지 못했다.** 만들 때 키가 없었다. 연결부는 각 회사 공식 문서(2026-11-14)의 요청·응답 모양대로 만들었고, 가짜 네트워크로 검사했다. 2026-11-14에 키 없는 실제 서버 호출 검사(`e2e/live-cors.spec.ts`)가 더해졌다. 이 검사는 요청이 브라우저의 사전 확인(CORS preflight)을 통과하고 서버가 HTTP 상태를 돌려주는 것까지만 본다.
- **Google Gemini에서 실제 키로 확인이 필요한 것:**
  - 그림 AI가 `safety_settings`를 받는지. 받지 않으면 그 값을 빼고 한 번 다시 보내게 해 두었다.
  - 그림이 막혔을 때 응답이 문서의 오류 코드대로 오는지.
  - 실제 키로 그림 응답을 받아 본 적이 없다. 머리글 없는 요청이 사전 확인을 통과하고 서버가 HTTP 상태를 돌려주는 것까지만 확인했다.
- **해결됨.** 브라우저에서 각 회사 서버(`generativelanguage.googleapis.com`, `api.openai.com`, `api.anthropic.com`)를 직접 부를 수 있는지(CORS)는 문서에 답이 없었는데, 2026-11-14에 키 없는 실제 브라우저 호출로 세 회사 모두 사전 확인 통과를 확인했다. Gemini 그림 요청에 붙이던 `Api-Revision: 2026-05-20` 머리글은 Google 서버가 사전 확인에서 거절해서(403) 그림 요청이 "Failed to fetch"로 실패했다. 이 머리글은 5월 응답 모양 변경 때의 옮겨 가기용 스위치이고 지금은 무시되므로 빼서 고쳤다(`PROVIDER_NOTES.md` 5장).
- **Claude에서 실제 키로 확인이 필요한 것:**
  - 진짜 서버가 요청 모양(`output_config.format`, 이어받기 `fallbacks`와 beta 꼬리표)을 받아 주는지.
  - 브라우저에서 직접 부르는 것이 허용되는지. 조직 설정에 따라 막힌 조직이 있다고 문서에 있다(응답 401, "CORS requests are not allowed for this Organization"). 이 문구가 있으면 앱은 "키가 맞지 않아요" 대신 "브라우저 사용이 꺼져 있어요"라고 따로 안내한다(`browser_blocked`).
  - 배열 길이 제한 없이도 쪽 수가 맞게 오는지. 어긋나면 한 번 다시 요청한다.
- `CLAUDE_BRIDGE=1 npx playwright test e2e/claude-subscription.spec.ts`는 요청 모양과 실제 Claude가 만든 글이 앱에서 읽히는지만 확인한다. 진짜 서버가 요청을 받아 주는지는 확인하지 못한다. 이 검사의 결과는 아래에 적는다.
  - 2026-11-14 결과: 통과. 가짜 Claude 키로 연결 확인, 줄거리 3개, 본문 4쪽 글이 실제 Claude(`claude-opus-5-5`, Claude Code 구독)의 답으로 채워졌다. 앱이 보낸 요청의 머리글과 본문 모양, 스키마 제한(배열 길이 제한 없음, `additionalProperties: false`)에도 문제가 없었다.
  - 그 뒤 기본 글 AI가 `claude-haiku-5-5`로 바뀌었다. 바뀐 기본값으로는 실제 답을 받아 보지 않았다.
- **OpenAI에서 실제 키로 확인이 필요한 것:**
  - 글 요청(`/v1/responses`)과 그림 요청(`/v1/images/generations`)이 문서의 모양대로 받아들여지는지, 오류 코드가 문서대로 오는지.
- 키가 있으면 `e2e/real-api.spec.ts`로 실제 호출 검사를 돌릴 수 있다. `GEMINI_API_KEY`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY` 중 있는 것만 돈다. 예: `ANTHROPIC_API_KEY=... npx playwright test e2e/real-api.spec.ts`
- 무료 한도의 분당·하루 횟수는 공식 문서에 숫자가 없어서 적지 못했다. Gemini는 Google AI Studio에서 확인해야 한다. OpenAI는 무료 한도가 문서에 없다. Claude는 무료 한도가 없다.
- OpenAI 그림 값은 장당이 아니라 토큰당(그림 출력 100만 토큰당 $30)이고 장당 값은 문서에 없어서, OpenAI로 책 한 권을 만드는 비용은 계산하지 못했다. Claude는 글만이라 책 한 권에 약 0.002달러다(기본 종류, `PROVIDER_NOTES.md` 8장).
- Claude는 기관용 안내(2026-11-14 확인)를 읽었지만, 키를 받는 사람의 나이 조건은 약관 원문으로 확인하지 못했다. OpenAI는 18세 미만 API 안내를 읽었지만 서비스 약관의 나이 조항은 확인하지 못했다. 세 약관 주소(`openai.com/policies/...`)가 자동으로 읽으려 하면 HTTP 403으로 막혔다. 사람이 브라우저로 직접 열어 확인해야 한다.
- Claude와 OpenAI가 입력한 내용을 어떻게 쓰는지, 결과물의 권리는 약관 원문을 확인하지 못했다.
- 자동 검사는 Chromium에서만 돌렸다. Safari와 Firefox는 직접 써 보지 않았다. Safari에서는 쪽을 그림으로 바꿀 때 처음 한 번 그림이 빠지는 일이 있다고 알려져 있다. 그럴 때는 받기 단추를 한 번 더 누른다.

## 알고 있는 한계

- **나이 조건.** Gemini는 약관상 18세 미만이 쓰는 서비스에 연결할 수 없다. Claude와 OpenAI는 조건부라서, 18세 미만이 쓰게 하려면 키를 받은 어른이나 기관이 회사가 정한 보호 조치를 갖춰야 한다. 이 도구는 나이 확인 장치와 지켜보고 신고하는 장치를 갖추지 못했고(서버가 없다), OpenAI의 13세 미만 개인정보 zero data retention 설정도 이 도구가 할 수 없다. 자세한 것은 `PROVIDER_NOTES.md` 2장과 선생님 안내서에 있다.
- **Claude 키만으로는 그림을 만들 수 없다.** Claude는 글만 만든다. 그림은 직접 올리거나 그림용 키(Gemini나 OpenAI)를 따로 넣어야 한다.
- 키를 브라우저에 둔다. 서버가 없는 구조라서 어쩔 수 없다. 같은 기기를 쓰는 다른 사람이 키를 볼 수 있으므로 "이 기기에서 키 지우기"를 꼭 안내한다. Google 문서는 키를 브라우저 쪽에 두지 말라고 권한다. Claude SDK도 브라우저에서 쓰려면 `dangerouslyAllowBrowser`를 켜야 하는데, 이름 그대로 같은 위험이 있다.
- 이 기기에 저장되는 책은 한 권이다. 여러 권은 작업 파일로 나눠 둔다.
- 브라우저 저장 공간을 지우면 만들던 책도 지워진다. 작업 파일을 받아 두는 것이 안전하다.
- 주인공 모습은 주인공 카드(글)로만 맞춘다. Gemini의 기본 그림 AI는 참고 그림을 받는지 확인하지 못했다. "자세한 설정"에서 다른 Gemini 그림 AI를 고르면 첫 그림을 참고 그림으로 보낸다. OpenAI 그림은 참고 그림을 보내지 않는다.
- 손글씨 글꼴(Gaegu)은 자주 쓰는 한글 2,350자만 담고 있다. 없는 글자는 또박또박 글씨로 보인다.
- 글이 글상자보다 길면 넘친 부분은 보이지 않는다. 글상자를 키우거나 글자 크기를 줄인다.
- 글상자는 쪽마다 하나다.
- 인쇄용 PDF의 색은 화면 색(RGB)이다. 인쇄소에서 CMYK로 바꾸면 색이 조금 달라질 수 있다.
- 연습 모드의 수채화 예시 그림은 가장자리가 조금 거칠게 보인다. 번짐 효과 때문이다.
- 처음 열 때 글꼴 세 개(합쳐서 약 1.7MB)를 받는다. 느린 인터넷에서는 글자가 먼저 기본 글꼴로 보였다가 바뀐다.
